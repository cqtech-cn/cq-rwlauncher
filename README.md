# CQ RWLauncher

**CQ RWLauncher** 是由 **畅轻科技工作室** 开发维护的 **Rusted Warfare（铁锈战争）轻量级启动器**。我们致力于为玩家提供更轻量、更直接、更易用的游戏启动、版本管理与模组安装体验。

> 本项目为社区开源项目，与 Rusted Warfare 官方无关。

- **官方网站**：https://cqrwl.cqfishnet.cn/
- **官方社区**：RTSBBS 畅轻铁锈社区（https://rtsbbs.cqfishnet.cn/）
- **交流反馈**：官方 QQ 群 `1067809448`

## 核心功能

CQ RWLauncher 为铁锈战争玩家量身打造，主要特性如下：

- **一键安装游戏**：从内置版本清单选择游戏版本并下载安装，支持多个游戏版本共存，下载进度实时可见。
- **实时下载进度**：下载时显示实时进度条与速度，支持取消操作，安装完成后自动刷新资源列表。
- **一键启动游戏**：自动检测 32/64 位游戏可执行文件，支持在启动时附加自定义命令行参数。
- **模组在线搜索**：对接末忆铁锈盒子开放 API，支持在线搜索社区模组与地图，一键下载并安装。
- **灵活配置**：支持自定义游戏路径、下载限速以及关闭窗口时的行为，可按需调整启动器外观。
- **绿色便携**：提供单文件程序与安装向导两种分发方式，配置保存在程序目录，方便备份和迁移。

## 技术栈

本项目采用前后端分离架构：

| 模块 | 技术选型 |
| :--- | :--- |
| **后端 / 核心逻辑** | Python 3（`backend/`） |
| **前端 / 界面** | Vue 3 + TypeScript + Vite + Element Plus（`frontend/src/`） |
| **桌面框架** | pywebview（`frontend/src/api/pywebview.ts`） |
| **打包与分发** | PyInstaller（`build/`、`CQ-RWLauncher.spec`）+ Inno Setup（`build/installer.iss`） |

## 快速开始

### 环境要求

- **Windows**（启动器主要面向 Windows 平台）
- **Python 3.10+**
- **Node.js 18+**（仅前端开发或构建时需要）

### 本地开发

1. **克隆仓库**
   ```bash
   git clone https://github.com/cqtech-cn/cq-rwlauncher.git
   cd cq-rwlauncher
   ```

2. **安装 Python 依赖**
   ```bash
   pip install -r requirements.txt
   ```

3. **安装前端依赖并启动开发服务器**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   前端开发服务器启动后，可在浏览器中调试界面。

4. **启动完整应用（前后端联调）**
   ```bash
   # 在项目根目录运行（具体入口请参考 run_dev.py）
   python run_dev.py
   ```

### 构建与打包

- **前端构建**：在 `frontend/` 目录下执行 `npm run build`，产物输出到 `frontend/dist/`。
- **Python 打包**：使用项目根目录的 `CQ-RWLauncher.spec` 配合 PyInstaller 进行打包。
- **安装包制作**：使用 `build/installer.iss` 通过 Inno Setup 生成 Windows 安装程序。

## 项目结构

```
cq-rwlauncher/
├── backend/              # Python 后端核心逻辑（版本管理、下载、FRP、诊断等）
├── frontend/             # Vue 3 + TypeScript 前端源码
│   ├── src/
│   │   ├── components/   # 可复用 UI 组件
│   │   ├── views/        # 页面视图（首页、下载、设置等）
│   │   ├── stores/       # Pinia 状态管理
│   │   ├── locales/      # 国际化语言包（zh-CN / en-US）
│   │   └── api/          # 与后端交互的接口封装
│   └── package.json
├── build/                # 构建配置、图标、Inno Setup 脚本
├── binaries/             # 第三方依赖说明（如 Locale Emulator）
├── tests/                # 单元测试与集成测试
├── requirements.txt      # Python 依赖
├── CQ-RWLauncher.spec    # PyInstaller 打包配置
└── run_dev.py            # 本地开发启动入口
```
